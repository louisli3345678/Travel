# Gate — 簽證／護照／入境／保險（中華民國護照 → 日本）

## A0: 結論 🟢 綠燈

| 項目 | 結論 | 來源 |
|---|---|---|
| 簽證 | 免簽，觀光最長 90 天（護照需有身分證字號） | [日本國家旅遊局 JNTO](https://www.japan.travel/tw/plan/visa-info/)、[風傳媒](https://www.storm.mg/article/11159846) |
| 護照效期 | 使用者「效期超過 6 個月」✅（日本規定涵蓋停留期間即可，6 個月為保守建議） | [gofunit](https://gofunit.com/entering-japan/) |
| 入境手續 | 建議出發前登錄 **Visit Japan Web**（非強制，可加速入境審查／海關申報／免稅），截圖保存 QR Code | [JNTO 香港](https://www.japan.travel/hk/plan/visa-info/visa-immigration/)、[japan-visa.com](https://japan-visa.com/zh-TW/for/taiwan) |
| 現金申報 | 攜帶超過 100 萬日圓需申報 | [gofunit](https://gofunit.com/entering-japan/) |
| 旅遊保險 | 非強制，但強烈建議（日本醫療費自費極貴） | 見 agent-E.md H1 |
| 禁止事項 | 免簽不得從事有薪工作 | [e-housing](https://e-housing.jp/zh-tw/post/multiple-entry-visa-japan-eligibility-validity-and-application-guide-zh-tw) |

距出發約 3 週，無需辦任何證件 → 🟢 直接進主體研究。
⚠️ 出發前到外務省／Visit Japan Web 官網再確認一次最新規定。
