# C — 交通

## C1: 租車（冬季推薦汽車）
- 馬公機場租車平均約 **NT$1,157／天**，部分低至 NT$900～937／天（平台資料，依車型日期變動）
- **機場取還車**：澎湖日昇租車有機場櫃檯（1 號出口旁）；夏戀租車會先電話聯絡取還車時間
- 證件：駕照正本＋身分證，部分要健保卡
- 冬季北風強，機車不安全 → 汽車
